# Brief rules

Use only information supplied in the notes. Identify the central point, then retain the decisions or details that change the reader's understanding. A claim described as uncertain must remain uncertain.

Put missing information under Unanswered questions. For example, if the notes do not identify an owner, ask who owns the task; do not assign an owner based on a name elsewhere in the notes.

The 80-token budget is a teaching convention for this sample. The helper counts whitespace-separated tokens, including Markdown markers, rather than applying a linguistic definition of a word.
