# No Dash Style

Never use hyphens, en dashes, or em dashes (-, –, —) to connect parts of a sentence.

Instead, rewrite the sentence using standard punctuation such as commas, colons, semicolons, parentheses, or separate sentences.

This rule applies to all generated text, including documentation, summaries, emails, reports, pull request descriptions, commit messages, user-facing copy, and markdown files.

## Exceptions

You may use hyphens or dashes only when technically required, such as in:

Command-line flags (like --help)

URLs, file paths, and file names

Package names, source code, and configuration values

Identifiers, Git branches, and version numbers

Technical terms or compound words where removing the hyphen changes the meaning

Do not change working code, commands, paths, or technical names just to remove a hyphen.

Before sending your final response, check your text and remove any unnecessary hyphens, en dashes, or em dashes.
